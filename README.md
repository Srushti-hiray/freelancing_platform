# 🚀 Freelancer Platform Backend

A robust and scalable backend service for a modern freelancing platform, built with NestJS and TypeScript.

## ✨ Features

### 🔐 Authentication & Authorization
- JWT-based authentication
- Role-based access control (Freelancer, Client, Admin)
- Secure password hashing with bcrypt
- Passport.js integration for authentication strategies

### 👥 User Management
- User registration and profile management
- Role-based user types (Freelancer, Client)
- Profile customization and verification
- Skills management and expertise tracking

### 💼 Project Management
- Create and manage projects
- Project categorization and tagging
- Project status tracking
- Detailed project descriptions and requirements

### 💰 Bidding System
- Place and manage bids on projects
- Bid negotiation features
- Bid history tracking
- Automated bid notifications

### 📊 Milestone Management
- Create and track project milestones
- Milestone approval workflow
- Progress tracking
- Payment scheduling

### 💸 Payment & Invoicing
- Generate and manage invoices


### 📨 Messaging System
- Real-time messaging between users
- Message history
- Notification system
- File sharing capabilities

### 📁 File Management
- Secure file uploads
- File type validation
- Storage management
- File sharing between users



## 🛠 Tech Stack

- **Framework**: NestJS
- **Language**: TypeScript
- **Database**: MySQL
- **ORM**: TypeORM
- **Authentication**: JWT, Passport.js
- **File Storage**: Local file system
